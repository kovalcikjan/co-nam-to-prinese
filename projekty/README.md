# Projekty

Sem si příkazy `/start`, `/odhadni`, `/rozhodni`, `/proverit` a `/zmer` ukládají tvoji práci. Každé rozhodnutí
má vlastní složku:

```
projekty/
└── pujcka-na-auto/
    ├── zapis.md        paměť projektu: co který krok zjistil
    ├── odhad.py        výpočet z kroku 1
    ├── odhad.html      výsledek s grafem, dá se poslat dál
    ├── rozhodnuti.py   výpočet z kroku 2
    └── …
```

Další krok si vždycky přečte `zapis.md`, takže nemusíš nic opakovat.

Obsah této složky se do gitu nenahrává (kromě tohoto popisu), tvoje data zůstanou na tvém počítači.

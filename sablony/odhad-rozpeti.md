# Šablona: odhad s rozpětím

Místo jednoho čísla rozlož výsledek na kroky a ke každému napiš tři hodnoty. Tabulku pak dej AI
(`/odhadni`, nebo prompt z [metody/1-nejistota/monte-carlo.md](../metody/1-nejistota/monte-carlo.md)).

**Co odhaduji:** [třeba přínos nové stránky v Kč za prvních 12 měsíců]
**Náklady:** [hodiny × sazba, nebo částka]
**Číslo z hlavy:** [co bys řekl bez výpočtu, ať je s čím porovnat]

## Referenční třída

Jak dopadly podobné věci: [třeba „z 5 podobných stránek se do top 10 dostaly 2“]

## Kroky

| Krok | Nejméně | Nejčastěji | Nejvíc | Odkud to vím |

| [CTR] | | | | |
| [konverze] | | | | |
| [hodnota konverze v Kč] | | | | |

## Výchozí stav

Co přijde i bez projektu (sezóna, růst trhu): [rozpětí]

## Tipy

- Rozpětí dávej tak, aby ses do něj trefil zhruba devětkrát z deseti. Z hlavy bývají moc úzká.
- U každého kroku napiš zdroj. Odhad je v pořádku, jen ho tak označ.
- Když jsou kroky na sobě závislé (vyšší pozice zvedne CTR i proklik), poznamenej to.
